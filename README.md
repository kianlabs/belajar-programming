# Belajar Programming

Repo untuk latihan dasar programming, mulai dari JavaScript.

## Isi

- `javascript/` — latihan dasar JS:
  - `pemanasan.js` — if / else sederhana (target belajar)
  - `pengulangan.js`, `pengulangan2.js`, `pengulangan3.js`, `pengulangan4.js` — latihan `for` + `if` (hitung, total, rata-rata)
  - `function.js`, `function2.js`, `function3.js` — latihan `function`, parameter, dan `return`

## Cara menjalankan

Pastikan [Node.js](https://nodejs.org/) terinstal, lalu:

```bash
node javascript/pemanasan.js
node javascript/pengulangan.js
node javascript/function.js
```
